# Financial Transaction Risk & Anomaly Intelligence

An end-to-end machine learning project for detecting financial transaction fraud and identifying anomalous transaction behavior.

## Project Status

🚧 In Development

## Objectives

- Explore financial transaction behavior
- Detect fraudulent transactions using supervised machine learning
- Identify anomalous transactions using unsupervised learning
- Handle highly imbalanced fraud data
- Develop meaningful transaction-level risk scores
- Explain model predictions
- Deploy the model using FastAPI
- Containerize the application using Docker
- Implement basic ML monitoring and drift detection
